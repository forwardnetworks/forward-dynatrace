# v0.13.5

Unreleased source version for the next enterprise-preview validation cycle.

- Adds an in-app, GET-only **Test connection** diagnostic using the selected Vault-backed Forward connection.
- Verifies configuration, Credential Vault resolution, HTTPS, authentication, network access, latest processed
  snapshot availability, and Read Only pilot posture without returning credentials or raw Forward data.
- Adds structured operational records with correlation IDs, bounded reason codes, duration, access profile, and
  snapshot state; authenticated error bodies and customer inventory remain excluded.
- Adds a customer-neutral sandbox enablement runbook and CI validation that binds its source-version marker and
  canonical DQL and Workflow references to repository assets.
- Keeps TLS verification mandatory and leaves Network Admin write behavior unchanged.
