# v0.13.4

This corrective release makes the Workflow action widget executable in current browsers.

- Removes invalid identity escapes from Unicode-mode regular expressions used to review plan and apply drafts.
- Retains the dual toolkit and hosted Workflows widget paths introduced in v0.13.3.
- Adds a regression test that parses every Unicode-mode regular expression in the synchronization widget.
- Requires release archives, installers, and release packages to contain both `/widgets/actions` and the current
  Workflows `/ui/widgets/actions` compatibility assets.
- Was exercised in an unsigned enterprise-preview tenant with a live on-demand Read Only workflow: the action widget
  rendered, the Workflow deployed, and a 1,000-relationship current-span plan completed with zero mutations.
- Keeps the Vault-backed connection contract, Read Only defaults, approval gates, and mutation behavior unchanged.
