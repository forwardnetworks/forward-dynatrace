# Forward for Dynatrace v0.13.1

This packaging-only patch publishes the v0.13 enterprise-preview integration without binding artifact creation to a
specific Dynatrace tenant. The application behavior, security boundary, RBAC model, dual-source discovery contract,
and Forward API workflow are unchanged from v0.13.0.

## Release Engineering

- Builds the app archive deterministically with the repository's exact pinned Dynatrace toolkit.
- Fails closed if the pinned toolkit version or archive-preparation entry point changes.
- Verifies the app identity, version, required app functions, settings schemas, and safe ZIP membership before
  publication.
- Keeps tenant OAuth and environment URLs out of the GitHub release workflow. OAuth is required only when an operator
  installs the verified archive into a Dynatrace tenant.
- Publishes the Dynatrace app as the sole installable, alongside its CycloneDX SBOM, checksums, optional detached
  checksum signature, and GitHub artifact attestations.

## Product Validation

- Complete Node.js 24 CI and release gates, including strict type checking, lint, schema, security, release, checksum,
  signature, SBOM, and immutable-ref tests.
- A 1,000-relationship scale cycle and 100-cycle deterministic reconciliation soak.
- Live non-production evidence for 1,000 current distributed-trace dependencies and 1,000 reachable modeled Forward
  paths.

Tenant installation and Credential Vault configuration remain post-release acceptance steps. Begin with a dedicated
Read Only Forward identity and promote to Network Operator or Network Admin only under the documented approval policy.

## Installable

`forward-dynatrace-app-v0.13.1.zip` is the only installable artifact. Download all assets from this release, verify
`SHA256SUMS`, validate the optional detached signature when present, and verify the app and SBOM attestations against
`forwardnetworks/forward-dynatrace` before installation.
