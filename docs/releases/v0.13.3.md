# v0.13.3

> Superseded by v0.13.4. Although this version restored the hosted widget path, its synchronization widget contained
> an invalid Unicode-mode regular-expression escape and could not execute in current browsers.

This corrective release restores installed Workflow action widgets on current Dynatrace tenants.

- Publishes byte-identical action widget assets at both the toolkit path, `/widgets/actions`, and the hosted
  Workflows compatibility path, `/ui/widgets/actions`.
- Keeps the action implementation, Vault-backed connection contract, Read Only defaults, approval gates, and
  mutation behavior unchanged from v0.13.2.
- Extends archive, installer, and release-package validation so future releases fail if the hosted widget path is
  missing.
